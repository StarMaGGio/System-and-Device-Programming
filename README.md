# System and Device Programming 💻

This repository contains the exercises carried out during the labs of the programming part of the course **System and Device Programming** in **Politecnico di Torino**

## Repository Structure 📂
- `Exercises`: Exercises on the different topics of the course
- `Lab01`: C/C++ IDE and UNIX reviews
- `Lab02`: C++ basics and sequential containers
- `Lab03`: Cpp Libraries (stack, queue, lambda, ...)
- `Lab04`: Synchronization (threads, tasks, promises, futures)
- `Lab05`: CUDA parallel programming
